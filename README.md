# Tameed Cybersecurity Awareness Games

Short, mobile-friendly games that help Tameed employees spot phishing, scams and everyday security risks.
Each game runs entirely in the browser, in Arabic and English, and takes about 3 minutes.

## Privacy

- No login, no tracking, no cookies.
- The player's name stays on their own device and is never sent or stored anywhere.
- Every game is a single self-contained file with no external requests.

## Maintenance

This repository is maintained by the Tameed Cybersecurity Team. External contributions are not accepted.

To update a game, upload the new version with **the same file name**. The link and any printed QR codes keep working.
